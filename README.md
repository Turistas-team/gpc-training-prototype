# GPC Ladders

Prototipo del ladder del **Grupo de Programación Competitiva de la UPC (GPC)**: una guía para avanzar desde Beginner, problemas para practicar y un espacio para seguir tu progreso en codeforces y en el grupo.

Inspirado en [GPC ladders original](https://github.com/aleiva17/gpc-ladders).
